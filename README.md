# Google TV Home

Turns a Google TV (or Android TV) into a calm, child-friendly one, reversibly: our own Home launcher
(`launcher/`) with kids' time and bedtime scenes, an Adult/Kids mode toggle and schedule, built-in remote
button remapping, less clutter, and a **Put the TV back** option that undoes all of it.

Setting up a new TV: see `AGENTS.md`. Undo everything: `./restore.sh <tv>`, or Settings (top-right corner) > Put the TV back on Home.
